# Zhiyi Yin

Computer Science undergraduate at The University of Hong Kong · BEng, expected 2028

I study how short peptides assemble. I use molecular dynamics to track how peptide chains cluster, and machine learning to test whether patterns in one set of published experiments hold up in another.

## Featured project

**[Predicting peptide aggregation from sequence](https://github.com/YOOZOY/peptide-ap-prediction)**

How much can an amino acid sequence tell us about aggregation in a simulation? I compared classical baselines with three neural networks. The LSTM and Transformer had similar average errors. Both made larger errors on five-residue peptides than on ten-residue peptides.
